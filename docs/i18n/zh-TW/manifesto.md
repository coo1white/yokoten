# 規則層

### 寫給 AI agent 時代的宣言

[English](../../manifesto.md) | [简体中文](../zh-CN/manifesto.md) | 繁體中文 | [日本語](../ja/manifesto.md)

寫程式碼已經不值錢了。一個團隊花一週才寫得完的東西，模型一分鐘就寫完。任何人只要一句提示詞，就能叫來十個工程師。

而沒有人在管。

Agent 直接推送到 main。它們改測試，改到過關為止。它們把你的金鑰貼進日誌。它們審查自己的成果，再給自己滿分。我們把工廠交給了不眠不休的工人，卻忘了把規矩一起帶來。

每一支像樣的軟體團隊都學過同樣的教訓，而且是用當機事故和泡湯的週末換來的：有人寫，另一個人審，最後由負責人拍板，沒有人能單獨上線。這些教訓，就要以機器的速度被丟掉了。

我們拒絕。

## 1. 提示詞是一個願望，守衛才是法律。

要求 agent 守規矩，不算控管。yokoten 在每個動作執行之前先檢查。違反規則，就不讓它執行。同一套規則今天已在七個 agent 上運作，從 Claude Code、Codex 到 Muse Code 和 Grok，每一個都經過一次真實執行的驗證。沒有哪個 agent 能獲得通融。

## 2. 沒有模型能自己批改自己的作業。

一家廠商寫，另一家廠商審。在我們自己的儲存庫裡，Grok 讀了 Claude 寫的程式碼，抓出兩個錯誤，必須修好之後程式碼才能合併。只有一個模型的團隊，就只有一組盲點。

## 3. 簽字的是人。

Agent 負責幹活，你負責拍板。修改規則本身、發布版本、任何無法復原的事：都要等一個簽名，而那個簽名是你的。

## 4. 一個人，就是一整間公司。

有了對的規則，一個人就能像真正的工程組織那樣調度一組 agent：有主管、有工人、有審查者，還有一塊讓你看著它們工作的看板。這不是玩具，這是一支團隊。

## 5. 每一台機器，同一個面板。

你的筆電、你的 Mac、你的伺服器、雲端。我們正在打造一塊看板，管理你擁有的每一台機器上的 agent，全都遵守同一套規則。一支艦隊，一部法律。

## 6. 一個專案學到的，每個專案都能拿到。

*Yokoten*（横展）這個詞來自豐田的工廠：在一條產線上找到的改善，推廣到每一條產線。某個 agent 犯過一次的錯，會變成一項檢查，yokoten 再把這項檢查提供給每個專案，讓下一個 agent 在重蹈覆轍之前就被攔下。

## 7. 送給全世界的禮物。

AI 的規則不該屬於哪一家廠商。yokoten 採用 MIT 授權，任何人都可以免費使用、修改，並在其上繼續開發。它是送給每一位開發者、每一個模型的禮物，不論開源或閉源，也能搭配你正在用的 agent。
