# 规则层

### 写给 AI agent 时代的宣言

[English](../../manifesto.md) | 简体中文 | [繁體中文](../zh-TW/manifesto.md) | [日本語](../ja/manifesto.md)

写代码已经不值钱了。一个团队一周的活，模型一分钟写完。谁都能一句话叫来十个工程师。

可是没人管。

agent 直接推到 main。测试过不了，就改测试。把你的密钥贴进日志。自己审自己的代码，给自己打满分。我们把整座工厂交给了不睡觉的工人，却忘了带上规矩。

每个像样的软件团队都学过同样的教训，代价是线上事故和熬掉的周末：有人写，别人审，负责人拍板，谁也不能一个人上线。现在，这些教训正以机器的速度被扔掉。

我们不答应。

## 一、提示词是愿望，护栏才是法律

叫 agent 守规矩，不等于管住了它。yokoten 在 agent 的每个动作执行之前先检查，违规就不执行。现在已经有九个 agent 跑着同一套规则。[指南里的 agent 表](guide.md#支持哪些-agent)是唯一的名单。Gemini CLI 只是列在这里，还没有完整跑过。哪个 agent 都没有特权。

## 二、不许自己批自己的卷子

一家写，另一家审。在我们自己的仓库里，Grok 审了 Claude 写的代码，抓出两个 bug，修完代码才能合并。只有一种模型的团队，只有一种盲区。

## 三、人来签字

agent 干活，你拍板。改规则本身、发布新版本，一切做了就收不回的事，都要等一个签名，而且是你的。

## 四、一个人，一整家公司

规则对了，一个人就能像真正的工程团队那样带一队 agent：有 lead，有 worker，有审查，还有一块看板让你看着它们干活。不是玩具，是团队。

## 五、所有机器，一块面板

你的笔记本、你的 Mac、你的服务器、云上的机器。我们正在做一块看板，管你每台机器上的 agent，全都守同一套规则。一支舰队，一部法律。

## 六、一个项目学到的，所有项目都得到

*横展*（yokoten）来自丰田的工厂：一条产线发现的问题，所有产线一起改。一个 agent 犯过一次的错，会变成一道检查，yokoten 把这道检查送到每个项目，下一个 agent 还没犯同样的错就会被拦下。

## 七、送给世界的礼物

AI 的规则不能归一家厂商所有。yokoten 用 MIT 许可，谁都可以免费用、改、在上面接着造。它是送给每个开发者、每个模型的礼物，开源模型和闭源模型都一样，和你已经在用的 agent 一起工作。

## 八、agent 经济的法治

先是管住一个 agent 的护栏。再是一支由互相竞争的厂商组成的 agent 团队。再是一家自己运转的公司，你坐在董事会里。然后是千千万万家这样的公司，在同一部共同法下交换工作：每一次事故都变成所有人的规则，每个 agent 都带着一份厂商没法美化的战绩，活干合格了才付钱。再然后，是 AI 做的每一种工作，不只是代码。

前两步今天已经在跑。第三步正在这个仓库里公开地建，建它的正是它描述的那支团队。剩下的是我们要去的地方，而且我们不打算小声说。
