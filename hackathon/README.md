# Hackathon submission

Draft materials for the Meta Global AI Developer Hackathon, Indie Dev track. The
submission deadline is 2026-11-04.

yokoten in one line: a safety net for one person working with many AI agents. Every
agent follows the same rules. The guard stops a risky action before it runs. A lesson
one project learns reaches the next project.

## Why this order

The judges look for creativity, technical ambition, and whether it works. The video
shows the working guard first, because that is the part a person can trust today. The
write-up explains the larger idea, and says plainly what is not built yet.
