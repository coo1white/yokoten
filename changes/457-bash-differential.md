Security

The guard now refuses code bash would run later but the guard cannot read: a PS4 or PROMPT_COMMAND substitution, an arithmetic, indirect or subscript expansion from a name the command hides, and a glob that a file name could turn into a writing option such as `git log *`. Write the program as a plain name and the value as plain text (#457).

The guard is held by a differential test against real bash: a recorded sandbox reports every program bash runs and every file it writes, and the test fails when the guard allowed something it did not see. A fixed corpus and seed keep CI reproducible; `YOKOTEN_DIFF_CASES` runs a longer local or nightly set (#457).
