Security

A plugin update applies on the next tool call. A guard which cannot be found refuses the call. The hook command is one short line. If that plugin folder is removed during a session, the tool call is refused and asks for a restart. A session which still has the old hook command needs one restart. Doctor's update note says the same. The launcher reads the account home from the password file, so a project setting for HOME cannot choose the plugin copy. A cache segment that contains a colon, or a Windows device name, is refused (#706).
