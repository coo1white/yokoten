Added

Agents of every vendor can now message each other with `yokoten msg send`, `inbox`, `who` and `log` (#674). Messages are files in a team folder next to your checkout; there is no server and no network. In a desk, an agent can write only its own outbox, so no one can fake a sender. Hooks add unread messages to the agent's context, marked as data that can't grant approval, and a claim of the owner's approval is flagged. Each message gets the same privacy and secret scan as posted text, and messages have size, rate and outbox caps. `yokoten desk` takes `--name` for the agent's name on the team.
