Fixed

The guard now refuses the other ways an agent could lose your work. That is deleting the checkout (`rm -rf .` or `..`), `git clean`, and `git checkout .` or `git restore .` of the whole tree. It also stops a forced checkout or switch, `git stash clear` and `git stash drop`. It stops `git gc --prune=now` or `--prune=all`, `git prune --expire=now` or `--expire=all`, `git reflog expire`, and `git filter-branch`. It stops moving the default branch with `git update-ref`, `git branch -f` or `git checkout -B`. It reads a shortened option as git does, so `--har` and `--del` are refused too. A repeated option counts by its last value. A path is read as the shell reads it: `src/a/..` is `src`, so it passes. `git restore -S .` passes because it only unstages (#828). A dry run counts only where git reads one: `-e` and `--exclude` take a pattern, so `git clean -fd -e --dry-run` is refused, and the last of `--dry-run` and `--no-dry-run` decides (#847).
