Changed

Every refusal keeps its four lines, and gains a fifth when the rule has words of its own: `Tell the AI: "…"`, a sentence a person who reads no code can say back to the agent. A worker says it to its lead instead, so a worker's refusal reads `Tell the lead:`. The words fit the case: a tag, a package, a repo made public. They also fit a download read before it runs, a key moved to an ignored file, and a project with no `yokoten.json`. A rule with no words of its own gets one plain sentence, never a rule id alone. The sentence is left out when a caller has none. The four lines, the board's parser and every reader of an older refusal keep working. The sentence speaks English or Simplified Chinese, from `YOKOTEN_LANG` or the usual locale variables.

The five protections now hold in a repo with no `yokoten.json` and in the user-level hook, with no `init` and no setting. Newly refused: creating a tag (#812), `git reset --hard`, and making a repo public (`gh repo create --public`, `gh repo edit --visibility public`). A shortened git option (`--har`, `--del`) and a second `--visibility` flag on `gh repo` are read the way git and gh read them. A download piped into a shell names the URL it runs. A tag inside the command a refusal hands back is quoted, so pasting it runs only that command. The guide opens with the five in plain words, in English and zh-CN (#816).
