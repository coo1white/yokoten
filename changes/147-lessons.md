Added

A reviewed lesson ships in the kit, and `yokoten doctor` runs it in every project. `yokoten learn --ship <id>` moves a lesson from `lessons/` into `kit/lessons/` with a row in the lessons table, and refuses while a `TODO(reviewer)` is left or its test fails. `doctor` runs each lesson's `findProblems` against the project (read only, offline) and shows what it finds as a note: `lesson incident-138: <what>; <fix>`. A note never fails doctor; "notNow" in `yokoten.json` stops a lesson. The first lesson is incident #138: a test that calls a server on this machine without setting `NO_PROXY`. The incident template gets a "Why it matters" field, which `learn` uses as the check's reason. **Kit change:** new projects get the field from `init`; a project that already has the template adds it by hand (#147).
