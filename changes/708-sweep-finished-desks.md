`yokoten gc` sweeps the desks of finished agents. It removes a clone or worktree whose tip is on the default branch and on the remote, with no live agent and no change of its own, ignored files included. The desk's state folder, its line on the board's desk list and its status file go too. The sweep keeps the main checkout and the session's own checkout. It keeps a desk with an open pull request on its branch. It keeps a desk with a commit on no remote branch, a change that is not saved, or a log changed in the last 24 hours. A desk the marker can't decide on is listed, never removed. That includes a desk whose remote can't be read, or whose default branch it can't tell. On macOS the sweep waits longer for the process list, so a busy machine does not hide a working agent. `yokoten gc --dry-run` prints what would go and changes nothing, not even a remote-tracking ref. `doctor` only lists what `yokoten gc` would remove, and `--json` includes that list; only `yokoten gc` removes a desk. The end of `yokoten desk` sweeps too. Paths in the home folder print as `~`. (#708)
