Added

The board can work on a second machine (#682).
`yokoten machine add <name>` adds one, reached by ssh or Tailscale.
The board shows its name, whether it is reachable, and its load: never an address or a user name.
A task starts there in a temp clone of the public repo, in a desk, under `nice`, with a memory cap.
The machine commits; the lead runs `yokoten machine fetch <name> <issue>` and pushes as the bot.
A machine without the agent's sign-in says so, and nothing is copied to it.
The board's engineer limit counts every machine.
